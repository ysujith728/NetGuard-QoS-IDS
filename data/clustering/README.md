# Clustering Track Dataset Documentation

## Dataset
CTU-13

## Track
Clustering

## Purpose
Unsupervised network traffic behaviour profiling, anomaly discovery, and structural cluster analysis.

## Official Source
- **Provider**: Stratosphere IPS Project / Czech Technical University (CTU)
- **URL**: [https://www.stratosphereips.org/datasets-ctu13](https://www.stratosphereips.org/datasets-ctu13)

## Expected Local File(s)
- CTU-13 scenario flow file(s) (e.g., `capture20110810.binetflow` or extracted NetFlow CSV files).
- The exact scenario number and file selection will be finalized during initial exploratory data analysis.

## Usage Instructions
- Download the selected CTU-13 scenario dataset file(s) from the official Stratosphere IPS repository.
- Place the downloaded dataset file(s) into this directory (`data/clustering/`).

## Git Notice
> [!IMPORTANT]
> Dataset files are intentionally excluded from Git tracking via `.gitignore` due to large file sizes. Ensure dataset files remain untracked.
